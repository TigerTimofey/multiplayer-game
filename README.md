## 🎮 Game Overview

A real-time multiplayer browser game where players compete to collect coins, battle each other, and store treasure. Features unique power-ups, hazards, and multiple game modes.

## ⭐ Features

### Multiplayer Mechanics

- Real-time multiplayer up to 4 players
- Room-based gameplay with unique room codes
- Player vs Player combat
- Real-time leaderboard

### Game Modes

- **Classic Mode**: Traditional coin collection and combat
- **Extra Coin Mode**: Start with bonus coins and faster movement
- **Hazard Mode**: Avoid dangerous hazards while collecting coins

### Power-ups

- 🏃 Speed Boost (W)
- 🛡️ Shield (E)
- ⚡ Teleport (R)
- 🔄 Grow (A)
- 🐉 Ultimate Dragon Form (Q)
- 👻 Invisibility (I)
- 💰 Double Coins (D)

### Gameplay Features

- Coin collection and storage system
- Treasure boxes for each player
- Coin stealing mechanics
- Player elimination system
- Match timer
- Dynamic hazards

## 🎮 How to Play

1. Visit [the game website](https://tigertimofey.github.io/multiplayer-game/)
2. Create a room or join existing one
3. Choose your character color and name
4. Use arrow keys to move
5. Collect coins and store them in your treasure box
6. Use power-ups (W,E,R,A,Q,I,D keys) to gain advantages
7. First player to store 25 coins wins!
